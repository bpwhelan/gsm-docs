# Custom name dictionary

Look up a character in Yomitan using names from the games you have played recently. The number of games and spoiler level you choose are included in the dictionary's update address.

1. In **Stats → Tools**, find **Download Special GSM Yomitan Dictionary**.
2. Choose **Number of games to include**. It defaults to the three most recently played games. Choose one if names from different games frequently overlap.
3. Choose a spoiler level. **No Spoilers** includes the photo, name and game. **Minor Spoilers** adds character information and relationships. **All Spoilers** can include plot details.
4. Select **Download Dictionary**. Import the ZIP under **Dictionaries** in the Yomitan instance where you read. Enable the dictionary and try a name from the game.

## Refresh the entries

Keep GSM running. In Yomitan's dictionary settings choose **Check for updates**, then **Update all**. Yomitan requests the latest entries from GSM using the game count and spoiler level saved in the ZIP. To change either choice, download a new ZIP with those settings.
