# Moving from scheduled plugins

The packaged desktop app no longer runs user scripts on a timer. If you used one in an earlier release, choose the built-in tool for the job.

| What the script did | Where to do it now |
| --- | --- |
| Remove repeated characters, menu lines or markup from incoming dialogue | Open [Text Processing](../features/text-processing.md). Preview a rule on a captured line, or add a per-game sentence exclusion. |
| Keep a large sentence database manageable | Open **Stats → Tools** for database maintenance and restorable [game archives](../features/stats-and-library.md). |
| Start a hook or OCR when switching games | Save the source for the game's scene in [Game Automation](../features/autolauncher.md). |
