# Record a session with subtitles

Longplay writes captured dialogue to an SRT subtitle file timed to an OBS recording.

1. Open GSM's main **Features** settings and enable **Generate Longplay**.
2. Start a hook or OCR and confirm dialogue is reaching the text feed.
3. Start a regular OBS recording, play through several lines, then stop the recording.
4. Open the recording in a media player and select the SRT beside it. For a recording named `MyGame.mkv`, look for `MyGame.srt`.

Use a recording for a subtitled playthrough. The replay buffer used for Anki card clips serves a separate purpose.
