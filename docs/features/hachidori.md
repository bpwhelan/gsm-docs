# Look up words with Hachidori

You can select Hachidori during [first launch](../getting-started/index.md) or switch later in **Settings → Dictionary → Lookup reader**. Hachidori keeps its own library and popup preferences.

![Desktop Dictionary settings with the reader selector and import controls](/img/desktop/dictionary-en.png)

1. Select **Hachidori**, then **Open Hachidori Settings**.
2. Import and enable a dictionary. Hachidori accepts Yomitan-format ZIP dictionaries. If you already use Hachidori in a browser, **Import from browser** in GSM can copy a supported browser profile. Close the source browser before importing.
3. Return to the game, activate the overlay and point at a word. Configure entry display, dictionary groups and Anki in Hachidori. Configure [controller navigation](./overlay-gamepad.md) in Overlay Settings.

![Hachidori showing a dictionary entry over game dialogue](/img/features/hachidori/dictionary-lookup.png)

To switch back, select **Yomitan** under **Lookup reader**. Its original library is available again.
