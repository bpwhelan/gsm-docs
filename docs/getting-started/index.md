# Install GameSentenceMiner

Choose a package from the [GSM releases](https://github.com/bpwhelan/GameSentenceMiner/releases). These guides cover the desktop rewrite. If you are trying a preview, open **Assets** on that release to find its installer.

- [Windows installer and managed OBS](./windows.md)
- [Linux AppImage and OBS](./linux.md)
- [macOS disk image and screen capture](./macos.md)
- [Steam Deck in Desktop Mode or streamed from a PC](./deck.md)

Linux and macOS users need to install FFmpeg separately for card audio and screenshots. Both platform guides include the installation steps.

## First launch

Choose your menu language and the language you are learning. In **Dictionary**, choose Yomitan or Hachidori and install a starter dictionary if offered. For Japanese, the guide also offers a Sudachi dictionary for readings and word selection.

![GSM setup guide at the language selection step](/img/desktop/setup-en.png)

Start your game and leave dialogue visible. Choose **Add a game** and check the capture preview. You can pause setup and resume from **Settings → General → Open setup guide**. Continue with [your first capture](../how-to-use-gsm.md). To save words as cards, also [connect Anki](./yomitan-anki.md).
