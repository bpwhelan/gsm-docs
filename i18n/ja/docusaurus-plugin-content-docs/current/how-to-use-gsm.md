# ゲームの台詞から最初のカードを作る

## 1. ゲームを追加する

[インストール](./getting-started/index.md)を済ませ、ゲームで台詞を表示します。**ホーム → ゲームを追加**から対象を選び、名前を付けます。保存前に映像を確認してください。OBSで作成済みのシーンを使う場合は、GSMでそのシーンを選びます。

![ゲーム選択、オーバーレイ操作、テキストフィードが並ぶホーム画面](/img/desktop/home-ja.png)

## 2. 台詞を一行取得する

ゲーム追加後にテキスト取得ウィザードが開きます（設定で有効な場合）。再度開くには、ホームで対象のゲームを選び、ゲーム名の横の **⋯** メニューからキャプチャウィザードを実行します。

- **テキストフック**は対応ゲームから台詞を直接取得します。フックを開始し、台詞を進めて全文が表示される項目を選びます。[テキストフックの設定](./features/text-hook.md)
- **OCR**は画面の文字を読み取ります。台詞の領域を選び、手動スキャンで全文を確認してから自動取得を開始します。[OCRの設定](./features/ocr.md)
- **音声だけの台詞**には実験的な[Windows音声認識](./features/windows-speech-recognition.md)を試せます。外部アプリからテキストを送る場合は[クリップボードまたはWebSocket入力](./settings.md)を設定します。

最後のステップで、このゲームの次回起動時に使う取得方法を保存します。台詞を進め、ホームのフィードに新しい行が届くか確認します。

## 3. 単語を調べる

ホームでオーバーレイを有効にします。初期設定で選んだリーダーで辞書を試します。未設定なら辞書をインポートして有効にしてください。台詞が画面にあるうちに設定済みのショートカットでオーバーレイを操作し、単語を指します。フックが台詞を送っているときも、単語の位置は画面から読み取れます。[オーバーレイの操作](./features/overlay.md)

## 4. カードを保存する

[AnkiとAnkiConnect](./getting-started/yomitan-anki.md)を起動し、OBSのリプレイバッファーを動かしておきます。辞書リーダーから単語をカードに追加すると、GSMが直近の台詞と照合して設定済みのメディアフィールドを埋めます。確認画面を有効にしている場合は例文、画像、音声を確認して確定します。Ankiでノートを開き、結果を確認します。[Ankiカードの強化](./features/anki-enhancement.md)
