# WindowsにGSMをインストールする

1. [リリース一覧](https://github.com/bpwhelan/GameSentenceMiner/releases)で使いたいバージョンを開き、Windows用の **GameSentenceMiner-Setup** をダウンロードして実行します。
2. GSMを開き、[初期設定](./index.md)を進めます。WindowsではGSMがキャプチャ用のポータブル版OBSを管理します。インストールの完了を待ちます。
3. ゲームを起動し、**ホーム → ゲームを追加**でウィンドウを選びます。保存前にプレビューで台詞が見えるか確認します。ゲームキャプチャで真っ黒になる場合はウィンドウキャプチャに切り替えて確認してください。

旧Windows版からアップグレードする場合、移行時にデータベースと設定のバックアップを作成できます。新しいアプリも同じデータフォルダーを使うため、試用中はそのバックアップを保管してください。

自分で用意したOBSを使う場合は、OBSの**ツール → WebSocketサーバー設定**でサーバーを有効にし、GSMのメイン設定の**OBS**にホスト、ポート、パスワードを入力します。カードにメディアを付けるにはリプレイバッファーを動かしておきます。

ゲーム画面が映ったら[テキスト取得の設定](../how-to-use-gsm.md)へ進みます。カードを作る場合は[Ankiも接続](./yomitan-anki.md)してください。
