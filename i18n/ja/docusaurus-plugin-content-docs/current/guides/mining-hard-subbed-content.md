# 焼き込み字幕からカードを作る

字幕が表示されているフレームで動画を一時停止します。OBSで映像と音声を取り込み、OCRで字幕を検索できるテキストにします。

1. OBSのシーンにプレーヤーのウィンドウか画面キャプチャを追加します。数秒再生してプレビューと音声メーターを確認します。カードにメディアを付ける場合はリプレイバッファーを有効にします。
2. GSMの**OCR → キャプチャ**でそのシーンを選びます。フレームを更新し、2行字幕も収まるように通常領域を指定します。カードに映像全体を残したい場合はOBS側をクロップせず、OCRの領域だけを絞ります。
3. 手動OCRを開始して字幕を一つ読み取り、取得結果を確認します。プレーヤーの操作ボタンも読み取る場合は領域を調整します。
4. 自動OCRを開始して動画を再生し、台詞がフィードに届くか確認します。その場面がリプレイバッファーに残っているうちに単語を検索し、[カードを作成](../features/anki-enhancement.md)します。

字幕の位置が複数ある場合は、そのシーンに[OCR領域](../features/ocr.md)を追加します。
