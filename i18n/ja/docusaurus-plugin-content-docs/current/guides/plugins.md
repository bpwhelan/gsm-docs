# 旧プラグインからの移行

新しいデスクトップ版では、ユーザースクリプトを定期実行する機能は廃止されました。以前の版で自動化していた作業には、次の機能を利用できます。

| やりたいこと | 操作 |
| --- | --- |
| 台詞の重複や制御文字を取り除く | [テキスト処理](../features/text-processing.md)でルールをプレビューします。メニューの定型文はゲームごとに除外できます。 |
| 台詞のデータベースを整理する | **統計 → Tools** でデータベースをメンテナンスするか、復元できる[ゲームアーカイブ](../features/stats-and-library.md)を作成します。 |
| ゲームを切り替えるときにフックやOCRを起動する | [ゲーム自動化](../features/autolauncher.md)でシーンごとに取得方法を保存します。 |
