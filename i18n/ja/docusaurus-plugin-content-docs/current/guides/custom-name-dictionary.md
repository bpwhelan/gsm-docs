# キャラクター名辞書

最近プレイしたゲームの登場人物をYomitanで検索できます。ダウンロード時に選んだゲーム数とネタバレの範囲が辞書の更新先に保存されます。

1. **統計 → Tools** を開き、**Download Special GSM Yomitan Dictionary** を探します。
2. 対象ゲーム数を選びます。初期値は最近遊んだ3作品です。作品間で同名の人物が多ければ1作品に絞れます。
3. **No Spoilers** は写真、名前、作品名のみ、**Minor Spoilers** は人物情報や関係を含みます。**All Spoilers** では物語の展開に触れる説明も表示されます。
4. **Download Dictionary** でZIPを保存し、実際に使うYomitanの辞書設定でインポートします。有効にして、ゲームの登場人物名で検索してみてください。

## 辞書を更新する

GSMを起動したまま、Yomitanの辞書設定で **Check for updates**、続いて **Update all** を選びます。保存してあるゲーム数とネタバレ設定で最新の項目が取得されます。この二つの設定を変更する場合は、GSMで選び直して新しいZIPをダウンロードします。
