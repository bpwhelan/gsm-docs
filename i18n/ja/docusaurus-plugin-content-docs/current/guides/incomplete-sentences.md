# 台詞の全文をAnkiに送る

カードの例文とGSMのテキストフィードを見比べます。フィードでも途中で切れていれば[フックの出力](../features/text-hook.md)または[OCRの取得結果](../features/ocr.md)を確認します。フィードは全文なのにカードでは句読点で切れる場合、Yomitanが送る例文の範囲を確認します。

たとえば、同じ吹き出しに「ありがとうございました。明日もよろしく。」と表示されていても、句点で区切る設定では後半の単語を引くと「明日もよろしく。」だけが送られる場合があります。

1. ブラウザー版Yomitanの**プロファイル**でGSM用のプロファイルを作ります。既存の辞書やAnki設定を引き継ぐには、今のプロファイルをコピーします。
2. **URL → Matches RegExp** でフィードのURLを指定します。標準のアドレスなら `^http://localhost:7275/texthooker(?:[/?#]|$)` です。ホスト名とポート番号はブラウザーのアドレスバーに合わせます。
3. そのプロファイルの **Text Parsing** で **Sentence termination characters** を **Newlines only** に変更します。
4. 同じ単語をフィードで引き、テスト用のカードを作成します。台詞の途中に改行が含まれる場合は、[テキスト処理](../features/text-processing.md)で改行を除くルールの結果を確認してから使用します。
