# テキストフックの設定

テキストフックは、ゲーム内部の台詞を読み取ってGSMに送ります。OCRよりきれいな文字を得られることが多いため、対応フックがあればまず試してください。現在の **Texthook / Agent** タブに、エンジン、フック、出力プレビュー、保存、トラブルシューティングがまとまっています。

<ImageFrame src="/img/desktop/texthook-ja.png" alt="現在のGSM Texthook / Agentタブ" caption="エンジンとフックを選び、出力を確認してゲームごとに保存します。" />

## フックを設定する

1. ゲームを起動し、GSMが正しいゲームやOBSシーンを認識していることを確認します。
2. Homeの **Run Capture Wizard** で **Texthook** に進むか、**Texthook / Agent** タブを直接開きます。
3. エンジンを選びます。
   - **Luna** または **Textractor**：対応するビジュアルノベルやゲーム向け
   - **Agent**：対応スクリプトがあるゲーム向け。**Search for hooks**で候補を探せます。
   - **MAGES**：対応するMAGESタイトル向けの実験的な組み込みフック
4. エンジンを起動し、フック一覧が表示されるまで待ちます。
5. 候補を選び、プレビューにゲームの台詞が正しく出るか確認します。読みやすい文章全体を出力するフックを選んでください。
6. **Save Hook**でこのゲームに設定を保存します。次回、自動的に同じフックを選ぶ場合は自動選択を有効にします。

**Output & timing**にはクリップボード出力などの項目があります。**Tools**にはエンジンの更新や修復、診断機能があります。

## フックが見つからない場合

- 一覧の別の候補を試します。最初の候補が台詞とは限りません。
- 重複表示やスクリプト情報ではなく、台詞全体が出力される候補を確認します。
- Agentでは、ゲームのバージョンと起動方法に合ったスクリプトを選びます。
- 使えるフックがなければ[OCR](./ocr.md)を設定します。外部ツールからWebSocketやクリップボードで入力する場合は[設定](../settings.md)をご覧ください。

:::note
テキストフックはWindowsとLinux/Wine/Protonで利用できます。対応状況はゲームとエンジンによって異なります。macOS版では現在このタブは表示されません。
:::

続けて[オーバーレイ](./overlay.md)と[Anki Enhancement](./anki-enhancement.md)を設定してください。
