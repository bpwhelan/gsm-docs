# テキストフックで台詞を取得する

Windows、または対応するWine・Protonゲームを動かしているLinuxで、ホームからゲームを選び、**Texthook / Agent**を開きます。現在のゲーム名と実行ファイルを確認します。

![検出したフックを表示するテキストフック画面](/img/desktop/texthook-ja.png)

1. エンジンを選びます。**Luna Hook**と**Textractor**は対応ゲームのフックを検出します。**Agent**はゲーム用スクリプトを使い、初回使用時にランタイムをダウンロードします。実験的な**MAGES**は一覧にあるタイトルが対象です。
2. エンジンを起動するか、**フックを検索**を選びます。ゲームの台詞を何行か進め、検出された行を選んで出力が実際の台詞と一致するか確認します。話者名やファイル名を拾うフックもあります。
3. すぐに保存するには**フックを保存**を選びます。フックを選んで異なる3行を取得した後は、フックとフィルターが自動保存されます。次回も使うには保存済みフックへの自動接続を有効にします。
4. ホームのフィードで台詞を確認します。毎回同じタグが混じる場合は[テキスト処理](./text-processing.md)でルールを試します。使えるフックがなければ、表示されている台詞を[OCR](./ocr.md)で取得します。

**出力とタイミング**で出力を調整し、**ツール**でエンジンを管理できます。ゲームに合わせて保存済み設定を起動するには[ゲーム自動化](./autolauncher.md)を参照してください。
