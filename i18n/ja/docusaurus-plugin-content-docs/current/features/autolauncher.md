# ゲームごとにテキスト取得を自動で開始する

ゲーム自動化はOBSシーンごとに使うフックやOCRの起動方法を保存します。たとえば、あるゲームでは保存済みのLunaフック、別のゲームでは自動OCRを起動できます。

1. **ホーム**でゲームを追加して映像を確認します。既存のゲームは選択後、名前の横の **⋯** メニューからキャプチャウィザードを実行します。
2. ウィザードで[テキストフック](./text-hook.md)を試すか、[OCR](./ocr.md)を設定します。台詞を一行進めて結果を確認します。
3. 最後のステップで次回起動時に使う取得方法を選び、保存します。別のシーンに切り替えて戻り、選んだ取得方法が起動するか確認します。
4. **ゲーム自動化**タブでシーンごとの起動設定を確認します。手動で起動したい取得方法は自動起動をオフにしておきます。

ホームの**ゲームを起動**はゲーム本体を立ち上げます。ゲームの起動オプションと、台詞を取り込む方法は別々に設定できます。
