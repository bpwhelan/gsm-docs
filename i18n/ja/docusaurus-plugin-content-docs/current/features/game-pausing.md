# 読んでいる間だけゲームを一時停止する

WindowsとLinuxでは、ゲームの一時停止機能でアクティブなOBSキャプチャに対応するゲームプロセスを停止します。安全に一時停止できるシングルプレイヤーゲームで使用してください。オンラインゲームやアンチチートを使うゲームでは、プロセスの停止が問題になる場合があります。

1. GSMのメイン設定の **Features → Game Pausing** で有効にし、一時停止用ホットキーと自動再開までの時間を設定します。
2. OBSでゲームのシーンを選びます。実行ファイル名の照合を有効にして、拒否リストを確認します。Linuxではキャプチャしているゲームまたはシーンの対象プロセスを指定します。ゲームプロセスを特定できない画面キャプチャでは一時停止の対象を決められません。
3. ホットキーを一度押して停止し、もう一度押して再開することを確認します。その後、必要なオーバーレイやAnkiの操作と連動させます。

オーバーレイの手動表示、テキストフィード、コントローラー操作、Ankiの確認画面は個別に停止を要求できます。一つを閉じても、別の停止要求が残っていればゲームは停止したままです。
