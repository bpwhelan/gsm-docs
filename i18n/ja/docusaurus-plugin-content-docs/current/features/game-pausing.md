# ゲームの一時停止

Game Pausingは、アクティブなキャプチャに関連付けられたゲームプロセスを一時停止します。ゲーム内にポーズ機能がない場合に、オーバーレイや台詞を確認するための**WindowsとLinuxで使える実験的な機能**です。

:::caution
プロセスの一時停止はゲームを不安定にする場合があります。オンラインゲーム、アンチチートを使うゲーム、ゲーム規約に触れる可能性がある環境では使わないでください。
:::

## 有効にする

1. **Settings → Features**で**Game Pausing**を開きます。
2. **Game Pausing**を有効にし、対象プロセスの確認や拒否リストを確認します。
3. 手動ショートカットと自動再開までの時間を設定します。
4. 自動一時停止を使う前に、シングルプレイヤーゲームで動作を確認します。

GSMはOBSのキャプチャに関連するプロセスを対象とし、実行ファイルを確認してから一時停止します。設定した時間が過ぎると自動で再開します。停止したプロセスの復旧操作も用意されています。

## 読書操作と連動する

オーバーレイの手動表示、Text Feedの表示、ゲームパッド操作、Anki確認画面を開いたときに一時停止を要求できます。設定は個別です。終了後にゲームが再開することを確認し、必要な連動だけ有効にしてください。

## 反応しない場合

- WindowsまたはLinuxでGSMを実行し、Game Pausingが有効であることを確認します。
- OBSが正しいゲームをキャプチャしているか、実行ファイル名が一致するか確認します。
- 拒否リストを確認します。
- 読書中に再開する場合は、自動再開までの時間を確認します。
