# 読書履歴とゲームアーカイブ

**統計**では読書時間、文字数、読書速度、語彙、マイニングの記録を確認できます。個別の作品は **Games**、読書目標の設定は **Goals** を開きます。

## 読み終えたゲームをアーカイブする

普段の検索に個々の台詞が不要になったら、ゲームのアーカイブ操作を使えます。GSMはアーカイブを書き出して検証してから、台詞を使用中のデータベースから取り除きます。ゲームの読書統計は残ります。メディアは参照情報だけが保存されるので、後で使う場合は元のファイルも保管してください。

**Tools → Saved Game Archives** に保存済みアーカイブとそのフォルダーが表示されます。復元すると台詞を再び検索できます。

## データベースを整理する

**Tools → Database Maintenance** でデータベースのサイズと回収可能な領域を確認します。**Vacuum now** で圧縮するか、定期メンテナンスの日程を設定できます。完了したゲームの自動アーカイブには、最後の台詞からの経過期間を別途指定します。0で無効になります。バックアップとデータフォルダーについては[設定](../settings.md)を参照してください。
