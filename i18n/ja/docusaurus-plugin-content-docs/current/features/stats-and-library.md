# 統計とゲームライブラリ

**Stats**タブでは、ゲームやセッションごとの読書時間、読んだ文字、速度、語彙や漢字の履歴、目標を確認できます。**Games**ライブラリではゲームの状態と読書記録を管理します。

## ゲームをアーカイブする

**Tools → Saved Game Archives**から、利用中の文データベースを小さくしながらゲームの文を保存できます。

- 個別または複数のゲームをまとめてアーカイブできます。
- アクティブなデータベースから文を削除する前に、GSMがZIPを検証します。
- 読書時間、文字数、セッション、速度、マイニング数、漢字、語彙の統計は維持されます。
- アーカイブした文は復元するまで検索に表示されません。音声や画像ファイル自体は複製されず、参照のみ保存されます。
- **Tools → Database Maintenance**からデータベースのサイズを確認し、手動圧縮や任意の定期メンテナンスを設定できます。

自動メンテナンスと自動アーカイブは初期状態では無効です。
