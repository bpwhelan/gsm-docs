# GSMオーバーレイ

ゲーム画面の上に辞書検索できる領域を重ね、別のウィンドウに切り替えずに台詞を調べられます。文字にマウスを合わせるかクリックすると、組み込みのYomitanが辞書を表示します。ツールバーから翻訳や台詞の操作もできます。

## オーバーレイを起動する

1. OBSを接続し、ゲームキャプチャを設定します。
2. GSMの**Home**タブから **Overlay Settings** を開き、キャプチャと操作方法を確認します。
3. Homeからオーバーレイを起動します。ゲームに合わせて自動で開閉する設定もあります。
4. 新しい台詞が表示されたら、ゲーム画面上の文字にカーソルを合わせるかクリックします。

<ImageFrame src="/img/desktop/overlay-overview.png" alt="現在のGSM Overlay Settings画面" caption="Homeから設定を開き、キャプチャ、表示、操作、ゲームパッドを設定します。" />

## オーバーレイのYomitanを設定する

オーバーレイにはゲーム内検索用のYomitanが組み込まれています。辞書や設定はブラウザー版Yomitanとは別に保存されるため、ブラウザーに辞書をインポートしてもオーバーレイには反映されません。

1. オーバーレイを開き、ツールバーから**Yomitan settings**を開きます。
2. オーバーレイで使う辞書ファイルをインポートします。複数の辞書を使う場合は有効化し、優先順位を調整します。
3. 新しい台詞を表示し、単語にカーソルを合わせるかクリックして辞書の内容を確認します。
4. オーバーレイ内のYomitanからAnkiカードを作る場合は、そのYomitanでもAnkiConnectとノートタイプを設定します。

推奨ノートタイプやフィールド設定は[AnkiとYomitanの設定](../getting-started/yomitan-anki.md)をご覧ください。そこにあるブラウザー版Yomitanの設定はオーバーレイへ自動では引き継がれないため、オーバーレイからカードを作る場合は必要な設定をそちらでも行います。

## 画面上の文字位置を認識する

オーバーレイには台詞の内容と画面上の位置が必要です。

- **テキストフック**が台詞を取得し、GSMが画面のOCRで単語位置を探します。
- **OCR**は台詞と画面上の位置を同時に取得します。詳しくは[OCRの設定](./ocr.md)をご覧ください。

文字は届くのに辞書検索できない場合は、OBSのキャプチャ対象と実際のゲーム画面が一致しているか確認してください。

<ImageFrame src="/img/desktop/overlay-capture.png" alt="現在のオーバーレイOCR設定" caption="Overlay captureでは、単語位置の認識に使うOCRとスキャン動作を調整できます。" />

## 台詞を調べて操作する

- ゲーム画面上の単語に**カーソルを合わせるかクリック**してYomitanで調べます。
- **オーバーレイツールバー**から翻訳や台詞の説明を表示できます。
- **フローティングテキストボックス**を使うと、ゲームの台詞全体を別表示できます。
- **Settings → Desktop → Dictionary → Lookup reader**では、日本語辞書リーダーの[Hachidori](./hachidori.md)も選べます。
- コントローラーで操作する場合は[Gamepad Navigation](./overlay-gamepad.md)を設定します。

ショートカットや表示方法は**Overlay Settings**内で変更できます。利用中のバージョンに表示されている設定を確認してください。

## 便利な設定

- **Open and close with active game**をHomeのOverlayカードで有効にすると、ゲーム開始時に開き、セッション終了時に閉じます。
- **Adaptive OCR Retries**は、台詞が表示中にローカルOCRを再試行する実験的な設定です。初期状態ではオフです。
- **Hide When Text Overlaps**は、オーバーレイの文字がライブ統計ウィジェットに重なる場合、一時的にウィジェットを隠します。
- Windowsでは追加のコントローラー入力方式を有効にできます。設定変更後はGSMの再起動が必要です。

## トラブルシューティング

### 辞書が表示されない

オーバーレイ内のYomitanに辞書をインポートし、新しい台詞で試します。ブラウザー版Yomitanの辞書は自動では共有されません。

### 検索位置が見つからない、またはずれる

OBSが正しいゲームを映し、台詞が表示されているときにフックイベントが届いていることを確認します。排他フルスクリーンで不安定な場合は、ボーダーレスまたはウィンドウ表示を試してください。

初回設定の流れは[GSMの使い方](../how-to-use-gsm.md)をご覧ください。
