# ゲーム画面で単語を調べる

1. [フック](./text-hook.md)または[OCR](./ocr.md)で台詞をテキストフィードに取り込みます。
2. **設定 → 辞書**でYomitanまたは[Hachidori](./hachidori.md)を選び、そのリーダーの設定で辞書を有効にします。対応ブラウザーの辞書はGSMのインポート機能でコピーできます。Firefoxではリーダーのバックアップを書き出して取り込みます。
3. **ホーム**でオーバーレイを有効にします。**Overlay Settings → Interaction**で起動ショートカットを確認します。台詞が見えている間にオーバーレイを操作し、単語を指すと辞書が開きます。

![読書、キャプチャ、操作設定に移動できるオーバーレイ設定](/img/desktop/overlay-overview.png)

## 単語の位置を特定する仕組み

テキストフックは画面座標のない台詞を送ることがあります。オーバーレイは文字がまだ映っているうちに画像をスキャンし、単語の位置を特定できます。設定は **Capture & OCR** にあります。ウィンドウを移動したりシーンを切り替えたりした後は、OBSのプレビューに同じゲームと台詞が映っているか確認してください。

![サイドバーから開いたオーバーレイのCapture & OCR設定](/img/desktop/overlay-capture.png)

## 台詞を読む・カードを作る

フローティングテキストボックスで全文を読むか、ゲーム上の単語を指して辞書を引きます。[AIプロバイダー](./ai-features.md)を設定するとツールバーから台詞の翻訳や解説を呼び出せます。単語をカードにするには、リーダーの[Anki連携](../getting-started/yomitan-anki.md)を設定してカード追加操作を使います。

コントローラーは **Overlay Settings → Controller** で設定します。ゲームに合わせて自動で開閉するには、ホームのオーバーレイ設定で該当項目を有効にします。[ゲームパッド操作](./overlay-gamepad.md)
