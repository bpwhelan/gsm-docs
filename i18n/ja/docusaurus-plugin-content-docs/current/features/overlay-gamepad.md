# オーバーレイのゲームパッド操作

コントローラーでゲーム画面の文字を移動し、Yomitan検索を開けます。先に[オーバーレイ](./overlay.md)を設定し、組み込みYomitanに辞書をインポートしてください。

## 設定する

1. **Overlay Settings → Controller**を開きます。
2. ゲームパッド操作を有効にし、接続状態を確認します。
3. コントローラーを接続し、ボタン認識をテストします。
4. 操作を有効にする方法と、使うボタンを設定します。

Windowsでは、まず標準の入力方式を試します。DirectInputやSDL用の拡張入力は任意設定で、変更後はGSMの再起動が必要です。対応状況はOSによって異なります。

## 操作とマイニング

- 方向入力で認識済みの文字ブロックや行内を移動します。
- **Modifier**ではボタンを押している間だけ操作し、**Toggle**ではボタンで操作モードを切り替えます。
- 文字単位または単語単位で移動できます。単語単位にはトークナイザーが必要です。
- 自動確定を有効にすると、移動先に合わせてYomitanを開きます。無効の場合は設定した確定ボタンを使います。
- Yomitanのポップアップを開いた後、確定ボタンでAnkiにマイニングします。キャンセルボタンで閉じるか操作モードを終了します。
- 左スティックでポインターを動かし、右スティックでポップアップをスクロールする設定もあります。

ボタン割り当てや連続入力の間隔は**Overlay Settings → Controller**に表示される現在の設定をご確認ください。

## トラブルシューティング

- コントローラーが一覧にない場合は、再接続して入力方式を確認します。
- 操作できても辞書が出ない場合は、オーバーレイが起動し、Yomitanに辞書が入っているか確認します。
- 移動が速すぎる、または遅い場合は連続入力間隔を調整します。
- Windowsで動かない場合は、拡張入力を有効にする前に標準入力方式を試します。
