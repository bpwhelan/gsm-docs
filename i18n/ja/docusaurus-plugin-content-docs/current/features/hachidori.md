# Hachidoriで単語を調べる

[初期設定](../getting-started/index.md)でHachidoriを選ぶか、後から**設定 → 辞書**のリーダー選択で切り替えられます。Hachidoriは専用の辞書ライブラリとポップアップ設定を使います。

![リーダーの選択とインポート操作があるデスクトップの辞書設定](/img/desktop/dictionary-ja.png)

1. **Hachidori**を選び、Hachidoriの設定を開きます。
2. 辞書をインポートして有効にします。Yomitan形式のZIPも読み込めます。ブラウザーでHachidoriを使用している場合は、GSMのブラウザーからのインポート機能で対応プロファイルをコピーできます。取り込み前に元のブラウザーを閉じてください。
3. ゲームに戻ってオーバーレイを操作し、単語を指します。辞書グループ、表示、AnkiはHachidori側で設定し、[コントローラー操作](./overlay-gamepad.md)はオーバーレイ設定で調整します。

![ゲームの台詞の上に表示されたHachidoriの辞書項目](/img/features/hachidori/dictionary-lookup.png)

元に戻すには、辞書リーダーとして **Yomitan** を選びます。以前のYomitanライブラリを再び使えます。
