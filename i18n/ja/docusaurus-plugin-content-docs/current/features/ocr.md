# OCRで台詞を読み取る

**OCR**タブで対象ゲームのOBSシーンを選びます。**キャプチャ**にはそのシーンの保存済み領域、読み取り結果、ショートカットが表示されます。台詞を表示した状態でフレームを更新して画像を確認します。

![動画の字幕を囲む読み取り領域を表示したOCRキャプチャ画面](/img/desktop/ocrframe-ja.png)

## 読み取り領域を指定する

プレビューでの領域編集が使える場合はその場で編集します。別ウィンドウで操作するには領域セレクターを開きます。折り返した2行目も含めて台詞を囲み、領域を保存します。保存した配置はエクスポートやインポートができます。

| 領域 | 効果 |
| --- | --- |
| 通常 | 自動取得や緑領域の手動スキャンで、この範囲の台詞を読みます。 |
| 除外 | HUDなど、読み取り範囲内にある不要な文字を除外します。 |
| セカンダリ | メニュー用の操作で読み取ります。選択肢などに使います。 |
| 排他 | この枠に収まる行があると、自動取得では排他領域内の行だけを残します。 |
| ブラックホール | 認識した文字が枠に重なると、その回の自動取得を破棄します。ポーズ画面の見出しなどに使えます。 |

## 一行試す

手動OCRを開始し、台詞が最後まで表示されたところで緑の領域をスキャンします。結果にメニューの文字が混ざる場合は領域を絞ります。台詞が表示される途中で読んでしまう場合は、認識設定のタイミングを確認します。二段階認識では文字が落ち着いてから本認識を実行できます。

連続して読むには自動OCRを開始します。次回も同じモードで起動するには、そのゲームのOCR自動起動設定で自動または手動OCRを選びます。ショートカット画面では台詞、メニュー、領域指定、ウィンドウ全体の操作を確認・変更できます。

台詞をフックで取得していても、[オーバーレイ](./overlay.md)はOCRで画面上の単語の位置を特定できます。
