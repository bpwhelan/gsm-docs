# テキスト処理

**Text Processing**タブでは、キャプチャしたゲーム文字を検索やカード作成に使う前に整形できます。制御文字、重複、ゲーム固有のマークアップなどを処理します。

## 処理パイプラインを作る

1. GSMの**Text Processing**タブを開きます。
2. 必要な処理だけ有効にします。文字列置換、重複文字や行の削除、制御文字・改行・数字の削除、かっこ内の抽出、行数制限、Unicode正規化などがあります。
3. 処理項目をドラッグして順番を決めます。上から下へ実行されます。
4. **Live Preview**にサンプルを貼り付け、処理前後を比較します。
5. 変更は自動保存されます。必要な台詞が残っていることを確認します。

最初は一度に一つの処理だけ有効にします。英語、数字、改行、日本語以外の文字を削除すると、混在言語や名前などが欠落することがあります。

不要文字が多い場合は、先に[テキストフック](./text-hook.md)で別のフックを試してください。処理ルールは、規則的な小さな修正に適しています。
