# 取得したテキストを整える

フックやOCRで毎回同じ不要な文字列が入る場合は、**テキスト処理**を開きます。実際の一行をプレビューに貼り付けるか、最新のゲームテキストを追従させて結果を確認します。

- 固定のタグは文字列置換の通常ルールで取り除きます。繰り返し現れるパターンには正規表現を使えます。
- `AAAABBBBCCCC` のような出力には文字の重複除去、行全体の重複には行の重複除去を試します。
- 処理は上から順に実行されます。項目をドラッグして並べ替え、置換が次の処理に与える影響を確認します。広い範囲に適用するフィルターでは、残したい名前や数字を含む例文も試してください。

変更は自動保存されます。編集中のプロファイルまたはゲームを確認してください。ゲームごとの除外文には、繰り返し現れるメニュー項目などを完全一致で登録できます。除外はテキスト処理前に行われます。大文字・小文字を区別し、前後の空白を無視し、文中の改行は保持します。
