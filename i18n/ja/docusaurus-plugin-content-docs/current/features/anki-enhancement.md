# Ankiノートにゲームの音声と画像を追加する

[AnkiConnectとノートタイプ](../getting-started/yomitan-anki.md)を設定します。Ankiを開いたままホームで接続を確認し、OBSでゲームの映像と音声を確認します。取得したい場面がリプレイバッファーに残っているうちにカードを作成します。

1. 台詞を取得し、その中の単語を引いて、辞書リーダーからカードに追加します。
2. GSMが新しいノートのタイプとタグを確認し、例文を直近の台詞と照合します。
3. プロファイルで有効な項目が書き込まれます。例文音声、静止画やアニメーション、振り仮名、前後の台詞、ゲーム名、AI出力などがあります。**設定 → Anki** で出力先と上書き・追記の設定を確認できます。
4. 確認画面を有効にした場合は例文、画像、音声を確認して確定します。セッションレビューを有効にすると、プレイ後にカードをまとめて見直せます。

![単語、編集できる例文、選択した画像が表示されたカード確認画面](/img/desktop/card-ja.png)

任意のAnkiBeaconアドオンを導入すると、カードを作成した時点でAnkiからGSMに通知されます。未導入の場合はGSMがAnkiConnectに新しいカードを問い合わせます。カードの項目が空なら[取得とカードの確認手順](../troubleshooting.md)を参照してください。
