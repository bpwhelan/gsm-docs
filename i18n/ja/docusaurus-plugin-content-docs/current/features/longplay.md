Longplay機能は、ゲームセッションの継続的なビデオ録画と同期した字幕ファイルを作成します。GSMがキャプチャしたゲームの各テキスト行は、ゲームプレイ中に表示されたタイミングに合わせてSRT字幕エントリとして書き込まれます。これにより、日本語テキスト字幕付きの視聴可能なゲームプレイ動画が作れます。復習、イマージョン、ゲームプレイの共有に最適です。ASBPlayerやさまざまなmpvツールなどを使ったセッション後の採掘にも活用できます。

<ImageFrame src="/img/features/longplay/longplay-demo.png" alt="SRT字幕付きのゲーム録画を再生するビデオプレイヤー" caption="MPVで日本語字幕付きのロングプレイ録画を再生" />

## 用途

- **復習セッション** — 字幕付きのゲームプレイを見直して理解を定着させる。
- **パッシブイマージョン** — 録画を後でリスニング/リーディング練習として視聴する。
- **進捗の追跡** — 時間の経過とともに理解度がどのように向上するかを確認する。
- **共有** — 注釈付きのゲームプレイを他の人と共有する。
- **セッション後の採掘** — ASBPlayerなどのツールを使って録画セッションから語彙を採掘する。

## 仕組み

<ImageFrame src="/img/features/longplay/srt-example.png" alt="ビデオファイルの隣にあるSRT字幕ファイル" caption="SRTファイルは同じベース名で録画の隣に自動的に配置されます" />

1. GSMはゲームプレイ開始時にOBSのリプレイバッファと一緒に録画を開始します。
2. プレイ中、GSMがキャプチャしたすべてのゲームテキスト行が **SRT字幕ファイル** に書き込まれます。
3. 各字幕エントリは、録画開始からの行の表示タイミングに合わせてタイムスタンプが付けられます。
4. 録画を停止すると、SRTファイルがビデオファイルと一緒に最終化されます。

SRTファイルは同じベース名でビデオファイルの隣に配置されます：

```
Game_2025-02-28.mkv
Game_2025-02-28.srt
```

ほとんどのメディアプレイヤー（VLC、mpvなど）は、ビデオを再生する際に字幕ファイルを自動的に読み込みます。

## 使用方法

1. GSMの設定（General タブ）で **Generate Longplay** を有効にします。
2. テキストキャプチャがアクティブになっていることを確認します（テキストフッカーまたはOCR）。
3. 通常通りゲームをプレイします。
4. 録画はリプレイバッファ録画と同時に開始されます。
5. GSMを閉じると、録画が停止してビデオとSRTファイルがOBSの録画フォルダに保存されます。

<ImageFrame src="/img/features/longplay/settings-toggle.png" alt="GeneralタブのLongplayトグル" caption="GeneralタブのシンプルなトグルでLongplayを有効にする" />

## 設定

| 設定 | 説明 | デフォルト |
|---|---|---|
| `Generate Longplay` | Longplay字幕生成を有効/無効にする | 無効 |

これだけです — Longplayはシンプルなトグルのみで、追加設定は不要です。

## Longplayと通常の採掘の比較

LongplayとAnki採掘は異なる目的を持ち、同時に実行できます：

| | 通常の採掘 | Longplay |
|---|---|---|
| **目的** | 個別のAnkiフラッシュカードの作成 | 字幕付きの視聴可能な動画の作成 |
| **トリガー** | Ankiでのカード作成時 | 録画中継続的 |
| **出力** | 音声クリップ、スクリーンショット、Ankiカード | フル動画 + SRT字幕ファイル |
| **OBSモード** | リプレイバッファ | フル録画 |
| **テキスト処理** | センテンスとカードのマッチング | すべての行を字幕として書き込み |

:::tip
両方を同時に使用できます！採掘のためにリプレイバッファを実行しながら、Longplay用に録画も行えます。
:::

## ファイル分割

OBSがファイルサイズ制限やフォーマット設定により録画を複数のファイルに分割する場合、GSMはこれを自動的に処理します — 現在のSRTファイルを最終化して、次のビデオセグメント用の新しいファイルを開始します。（これが正しいか確認が必要です）

## 前提条件

- **OBS** が接続されて **録画**（リプレイバッファだけでなく）用に設定されている。
- **テキストキャプチャ**がアクティブ（テキストフッカーまたはOCR）。
