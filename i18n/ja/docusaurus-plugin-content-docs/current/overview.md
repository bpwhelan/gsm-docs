# GameSentenceMiner

GameSentenceMiner（GSM）はプレイ中の台詞を取り込みます。一行ずつフィードで読み返したり、ゲーム画面で単語を調べたり、その場面の例文、音声、画像をAnkiカードに保存したりできます。

## 一つのゲームで始める

1. [デスクトップ版をインストール](./getting-started/index.md)し、初期設定で辞書を選びます。
2. [ゲームを追加して台詞を一行取得](./how-to-use-gsm.md)します。対応するゲームには[テキストフック](./features/text-hook.md)、画面に表示された文字には[OCR](./features/ocr.md)を使えます。字幕のない音声には実験的な[Windows音声認識](./features/windows-speech-recognition.md)もあります。
3. [オーバーレイで単語を検索](./features/overlay.md)します。読書と読書記録だけならAnkiは不要です。
4. カードを作りたいときは[Ankiを接続](./getting-started/yomitan-anki.md)し、[最初のカード](./features/anki-enhancement.md)を確認します。

## 次のセッションへ

[ゲーム自動化](./features/autolauncher.md)を設定すると、ゲームごとに取得方法を切り替えられます。[テキスト処理](./features/text-processing.md)で繰り返し現れる不要な文字を除去し、[Longplay](./features/longplay.md)で録画に字幕を残せます。過去のセッションや目標は[統計とライブラリ](./features/stats-and-library.md)で確認できます。

うまくいかないときは[取得とカードの確認手順](./troubleshooting.md)を参照してください。[GSM Discord](https://discord.gg/yP8Qse6bb8)や[GitHubの問題報告](https://github.com/bpwhelan/GameSentenceMiner/issues)でも相談できます。
