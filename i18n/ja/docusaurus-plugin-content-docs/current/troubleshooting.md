# 取得が止まった箇所を調べる

画面に表示されている台詞を一行選び、ゲームからカードまでどこに届いたかを順に確認します。

| 状況 | 確認すること |
| --- | --- |
| ホームでOBSが未接続 | 自分で用意したOBSでは、WebSocketサーバーのホスト、ポート、パスワードをGSMのメイン設定の**OBS**と一致させます。 |
| OBSは接続済みだが別の画面が映る | OBSでシーンを選び直します。OCRを変更する前にソースの対象ウィンドウとプレビューを確認します。 |
| 映像は正しいが台詞が届かない | [フック](./features/text-hook.md)では台詞を進め、選択中のフックの出力を見ます。[OCR](./features/ocr.md)では手動OCRを開始して台詞の領域をスキャンし、取得結果を確認します。 |
| 台詞は届くが辞書の項目が出ない | 使用中の[辞書リーダー](./features/overlay.md)で辞書を有効にします。ブラウザー版Yomitanとオーバーレイは別々に辞書を管理します。 |
| フィードには全文があるがカードでは句点で切れる | カードを作ったプロファイルの[Yomitanの文区切り設定](./guides/incomplete-sentences.md)を確認します。 |
| カードはできるがゲーム音声や画像がない | ホームでAnkiの接続を確認し、GSMでノートタイプとメディアのフィールドを確認します。OBSで映像と音声メーター、リプレイバッファーの動作を確認し、もう一度台詞を再生して新しいカードを作ります。 |

解決しない場合は、GSMのバージョン、OS、テキストの取得方法、最初にうまくいかなかった手順と関連するログを添えて相談してください。[GSM Discord](https://discord.gg/yP8Qse6bb8) · [GitHubの問題報告](https://github.com/bpwhelan/GameSentenceMiner/issues)
